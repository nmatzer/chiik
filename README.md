# CHIIK · Tabla de referencias ideales

Aplicación web instalable (PWA) que muestra los valores objetivo publicados en las guías de manejo de ponedoras (Lohmann, Hy-Line, H&N, Dekalb), pollo de engorde (Ross 308, Cobb 500) y reproductoras (Ross 308 PS, Cobb 500), por línea, sistema, sexo y edad. Funciona sin conexión después de abrirla una vez.

- Cada valor enlaza a la guía oficial del fabricante y a la página del PDF.
- No se interpolan, extrapolan ni estiman datos: un hueco se muestra como «Sin dato oficial».
- Las tablas pertenecen a sus fabricantes; CHIIK es una herramienta de consulta y no sustituye la guía ni el criterio veterinario. Revisión veterinaria pendiente.

`informe-datos.md` resume la última importación y validación de datos.
